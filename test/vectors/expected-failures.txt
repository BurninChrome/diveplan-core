# Known deviations from the conformance vectors.
#
# Format:  <vector file>  <expected checks>  <expected skips>  <allowed failures>  <reason>
#
# The vectors say how the model SHOULD behave. Each line records a place where
# this library currently does not, so CI stays green on known defects and fails
# on new ones.
#
# THREE ways a line can fail the build, all deliberate:
#
#   more failures than allowed   a regression
#   fewer failures than allowed  a defect was fixed; update this file in the
#                                same change, so a fix cannot land claiming
#                                more or less than it delivered
#   wrong check count            the vector file was truncated, corrupted or
#                                lost. Without this a deleted corpus reports
#                                success.
#   wrong skip count             same, for rows that are currently unreachable.
#                                83% of gradient-tolerance.tsv is skipped, so
#                                without this it could lose most of its content
#                                unnoticed.
#
# A file listed here that produces no checks at all is reported MISSING.
# A file that produces checks but is not listed here fails too.
