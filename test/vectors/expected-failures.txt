# Known deviations from the conformance vectors.
#
# Format:  <vector file>  <allowed failures>  <reason>
#
# The vectors say how the model SHOULD behave. Each line here records a place
# where this library currently does not, so CI stays green on known defects
# while still failing on new ones.
#
# The runner treats FEWER failures than allowed as an error too: if a defect is
# fixed, this file must be updated in the same change. That is deliberate — it
# is how a fix proves it did what it claimed.
#
# Fixing a finding means decreasing a number here, usually to zero, and then
# deleting the line.

ceiling.tsv             24   getCeiling() evaluates each gas independently instead of blending a/b by partial-pressure share. All 24 mixed-gas vectors deviate; single-gas vectors pass. See .okf/findings/ceiling-vs-mvalue-divergence.md

gradient-tolerance.tsv  90   No GF-aware entry point exists. Only the 18 gf=1.0 vectors can be checked at all (they reduce to the raw ceiling and pass); the other 90 are unreachable until the library grows a tolerated_pressure() primitive. See .okf/domain/ascent-and-stop-scheduling.md
